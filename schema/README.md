# Canonical schema

This directory contains machine-readable definitions for the project data model.

Current status: **v0.1 bootstrap / not yet fully reconciled against all existing workbooks**.

Files:

- `entities.yml` — scientific/domain entities and their grain
- `fields.yml` — canonical field definitions
- `controlled_vocabularies.yml` — shared statuses and vocabularies

The schema should become the common source for workbook data dictionaries, validation, application forms/views and database mappings.
