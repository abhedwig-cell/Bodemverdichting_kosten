# Tollebeek 1998 managed-boundary evidence route v0.1

Status: **HISTORICAL SYSTEM ROUTE QUALIFIED, EVENT BOUNDARY NOT ADMITTED**

## Decision

The project can now distinguish the historical 1998 control system from the current Tollebeek system, but it does not yet possess an event-specific managed-boundary series. `DR_SM_MANAGED_BOUNDARY` therefore remains `PARTIAL_EVIDENCE`.

## Historical system constraints

The official 2006 peilbesluit retained the earlier peil regime and described separate De Rietgors (OT02), De Fuut (OT03) and De Kievit (OT04) underbemalingen at NAP -6.20 m. It lists pump capacities of 2.600, 0.670 and 1.000 m3/s and direct discharge to the Urkervaart. The same source explicitly distinguishes streefpeil from actual water level and allows larger departures during persistent heavy rainfall.

Owner retrospective evidence shows that the modern connecting watercourse and IJsvogel system are post-1998 adaptations. The 1998 event also involved emergency pumping and system exceedance. Consequently the current merged OT.02/IJsvogel system cannot be used silently as the 1998 event boundary.

## Missing event controls

No admitted source currently provides a complete 1998 time series for local surface-water level, Urkervaart level, pump runtime/realized discharge, stuw/inlaat operation or emergency-pump deployment. Nominal target and nameplate capacity therefore remain constraints/context rather than numerical event boundary values.

## Spatial consequence

The admitted current OT.02 polygon is valid as current peilgebied identity/profile sampling domain, but historical boundary control was split across at least Rietgors/Fuut/Kievit. A future source-model mapping must therefore resolve which admitted profile/model units belonged to which historical control unit or justify an explicit equivalence. This workunit does not synthesize historical subarea polygons.

## Paired-run rule

Once a managed boundary is qualified, CURRENT and REFERENCE runs must use identical or explicitly equivalent boundary semantics so that compaction attribution is not confounded by control changes. This rule does not authorize an invented boundary.

## Next route

Use the owner water-information request route for event-period levels and control logs. If direct telemetry cannot be recovered, review a separate historical reconstruction protocol with explicit uncertainty and provenance before mapping anything into a source model.
