# 2. Theoretical framework

## 2.1 Object of study

Soil compaction changes soil structure and can alter rooting, water retention, hydraulic conductivity, infiltration, drainage and surface runoff. The economic consequence depends on where these physical changes propagate through agricultural production and the regional water system.

## 2.2 Separation of state, response and consequence

The framework distinguishes:

- **soil state**: physical condition such as bulk density, texture, organic matter and compacted-layer geometry;
- **response**: hydrological or crop response under specified forcing and boundary conditions;
- **attribution**: difference between a current and a matched reference state;
- **transfer**: movement from parcel-generated response to receptors or managed systems;
- **valuation**: translation of a qualified physical consequence to a cost category.

## 2.3 Counterfactual logic

Attributable impact is defined by a paired comparison in which only the soil-state dimension intended for attribution changes. Weather, crop, geometry and boundary assumptions should otherwise be controlled.

## 2.4 Event and annual scales

Annual volumes may be additive, but peaks, occurrence, routing, capacity pressure and damage are generally nonlinear. Event timing and antecedent state therefore remain explicit where relevant.

## 2.5 Water-system distinction

The framework separates:

**generated parcel runoff → field-edge occurrence/volume → ditch/network transfer → managed-system routing/dispatch → capacity/energy → cost**.

A single static delivery factor is not assumed as a universal project default.

## 2.6 Uncertainty

Uncertainty is attached to the layer where it originates. Missing physical state, uncertain transfer, conflicting asset ratings and valuation uncertainty should not be collapsed into one generic confidence score.

## 2.7 Open theoretical work

The theoretical section still needs a curated literature synthesis for yield, rooting, hydraulic functions, runoff generation, water-system transfer and valuation. Source-level evidence belongs in the evidence register rather than being embedded only in prose.
