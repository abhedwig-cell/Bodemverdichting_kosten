# Tollebeek 1998 land-use evidence route v0.1

Status: **HISTORICAL CONTEXT ROUTE QUALIFIED, EVENT CROP NOT ADMITTED**

## Decision

`DR_SM_LAND_USE` advances from `MISSING` to `PARTIAL_EVIDENCE`. Broad land-use context and historical map routes are now explicit, but the project still lacks event-relevant crop/vegetation identity at source-model grain for October 1998.

## What is known

Near-period official Tollebeek documentation describes the historical Rietgors/Fuut/Kievit areas as predominantly arable agricultural land, with forest also present in Rietgors and Kievit. LGN3 and LGN4 provide national historical spatial context before and after the event.

For Flevoland, LGN3 agricultural classification uses 1995 imagery. LGN4 uses 1999/2000 imagery. The LGN methodology warns that crop-type changes can simply reflect crop rotation. Therefore neither map, nor interpolation between them, establishes the exact crop in 1998.

The public RVO/PDOK annual Gewaspercelen archive documents historical annual datasets from 2009 onward, so this high-quality parcel/crop route does not reach the event year.

## Model consequence

Vegetation/crop can affect rooting, transpiration and interception. A paired soil-compaction attribution experiment must therefore keep land-use/crop semantics identical across CURRENT and REFERENCE unless vegetation is intentionally part of the scientific contrast. Missing crop information may not be hidden behind a representative crop default.

If exact 1998 crop evidence cannot be recovered, a later model-design workunit may test whether the event experiment can be defined as explicitly crop-independent or as a bounded scenario. Such a scenario is not observational admission.
