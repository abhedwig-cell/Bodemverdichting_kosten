# 1. Project overview

## Purpose

The project develops a defensible system for estimating costs of soil compaction for agriculture and society, with explicit distinction between on-site and off-site consequences.

## Core causal chain

**soil compaction → soil physical/hydraulic state → parcel water balance → water-system response → societal effect → valuation**

## Main modelling principle

The project does not jump directly from a compaction class to euros. It separates at least five layers:

1. measured or inferred soil state / exposure;
2. physical and hydrological response;
3. attribution to a current versus reference soil state;
4. transfer through the water system;
5. valuation and cost category.

## Current focus

The most developed off-site route is water. Nutrients and other pathways can be added later under the same architecture.

## Audience

Primary users include WENR/WUR researchers, project colleagues, policy clients and domain experts who need to understand both the calculation and its evidential status.

## Scope guardrails

- unknown is not zero;
- generated runoff is not automatically delivered runoff;
- delivered runoff is not automatically pump volume;
- a historical cost benchmark is not a current unit cost;
- a broad soil class is not a crop-specific or profile-specific response;
- current and reference states must be explicit for attributable damage.

## Current implementation state

A substantial prototype exists in Excel workbooks and supporting scripts. The GitHub repository is being established as the canonical scientific and technical structure before further application development.
